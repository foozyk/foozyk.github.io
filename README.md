# Наш год — 365 вопросов

PWA для пар. Помогает говорить о важном, когда трудно.

- **Вопрос дня** — говорить каждый день
- **Примирение** — после ссоры
- **Договорённости** — договариваться

Всё остальное — служит этим трём вещам или не нужно вовсе.

**Пользователи:** Руслан (Android) и Юлия (iPhone).

---

## Стек

- **Firebase Auth + Firestore** — аккаунты, данные, real-time через `onSnapshot`
- **ES-модули, без сборки** — файлы подключаются напрямую
- **PWA** — `manifest.json` + `sw.js` (service worker)
- **Bubblewrap TWA** — Android-обёртка живёт отдельно: `C:\nashgod-android`
- **Типографика:** DM Serif Display (заголовки) + Manrope (тело)
- **Палитры по экранам и состояниям** — тёмная тема, переход 700ms

## Разделы приложения

- **Сегодня** — вопрос дня, полароиды, пульс-кружок, CTA «Сохранить ответ»

## Как работать с кодом

- **Формат правок:** НАЙДИ → ЗАМЕНИ, никогда diff
- **Порядок:** HTML → CSS → JS → «всё работает» → дальше
- Документы — одним code-блоком целиком
- Живые превью перед патчем
- Не менять рабочее без запроса
- **Не удалять данные Firestore** без явного запроса
- Не рефакторить без запроса
- Не додумывать. Варианты обозначать буквами (A/B/C)
- **Тон:** по-русски, кратко, «ты», не «Вы»

## Ограничения

**Не возвращать:**
Забота · Пульс месяца · Пульс партнёра · Задачи · Календарь · Планы · Послания · Важные даты · Ритуал воскресенья · Память «Помнишь?» · Голос · Фото как фича · Иконка-кардиограмма · Рефлексия · Совместный дневник · Мини-уроки в шапке «Мы» (только в под-табе Уроки) · Бейджи/стрики/счётчик дней · Цветовые схемы · Переключатель темы · Плашка `#headerPause`

**Технические запреты:**
- `background` **не вешать на `body`** — только на `#main-screen::before` как fixed-слой
- Не переопределять `--nav-active` для состояний тихий день/примирение
- Полароиды: `--tx` во всех состояниях

**Новые фичи — стоп до месяца наблюдений.** Топ-5 на возврат: **T** (Я-сообщение) · **Q** (Копилка благодарностей) · **A** (Мостик) · **S** (Тихий час) · **J** (Слепой обмен).

## Разработка

Проект без сборки. Открывай `index.html` локально или запусти простой HTTP-сервер:

```bash
python -m http.server 8000
```

и открой `http://localhost:8000`.

**Важно:** для работы service worker и Firebase Auth нужен `http://` или `https://`, не `file://`.
